# 优课在线自动刷课悬浮助手 (uooconline autoplay panel)

> 一段直接粘贴到浏览器控制台就能用的 **优课在线 (uooconline.com) 自动刷课脚本**，带悬浮控制面板：自动获取全部课程视频、倍速播放、静音、自动连播、自动跳过已完成、自动复核完成度、100% 自动收工。

## 功能特性

- 🎯 **一键获取全部视频**：自动遍历所有章节/小节，拉取全部视频资源（标题、任务点、完成状态）
- 🖥️ **悬浮控制面板**：可拖拽、可最小化，实时显示进度条 / 当前视频 / 运行日志 / 视频清单
- ⚡ **倍速播放**：2x / 4x / 8x / 10x / 12x / 16x 自由切换
- 🔇 **自动静音**：后台挂机不打扰
- 🔁 **自动连播**：播完一节自动切换下一节，平台自动重播时自动检测并继续
- ✅ **服务端确认**：每个视频播放后直接查询服务端完成状态（`finished`），确认完成才切换，不漏刷
- 🧹 **自动复核（sweep）**：全部播完后重新拉取完成状态，自动补刷遗漏视频
- 🏁 **完成自动停止**：检测到所有视频完成度 100% 后自动停止
- 💾 **进度持久化**：完成记录存入 localStorage，误刷新页面后重开脚本可继续

## 使用方法

1. 用 Chrome 打开优课在线的课程学习页面（`https://m.uooconline.com/home/learn/index#/...`）
2. 按 `F12`（或右键 → 检查）打开开发者工具，切到 **Console / 控制台**
3. 把 [`uoo-autoplay.js`](./uoo-autoplay.js) 的全部内容粘贴进去，回车运行
4. 点击悬浮面板上的「开始」按钮即可挂机

> 建议保持标签页可见（不要最小化），窗口不要关闭；中途关闭后重新粘贴脚本即可续刷（服务端已完成的视频会自动跳过）。

## 工作原理

- 通过课程接口 `getUnitLearn` 遍历章节树，拿到全部视频资源与完成状态
- 用 ui-router hash 导航到每个视频资源页，接管页面原生 `<video>` 元素
- 控制倍速（`playbackRate`）与静音（`muted`），并对抗播放器重置
- 监测平台"自动重播"，每个视频周期性查询服务端完成状态，确认后才切换
- 全部任务点完成后自动复核一轮，未达 100% 的自动重刷

## 适用范围

- 优课在线 / 深大优课 (uooconline.com) MOOC 课程
- 课程页面带视频任务点（任务点视频占平时成绩的常见模式）
- 同类平台（超星学习通、雨课堂等）暂不支持
